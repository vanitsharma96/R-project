STUDENT PERFORMANCE ANALYSIS USING R
=====================================

Files:
1. student_performance_analysis.R - complete R script
2. students.csv - sample dataset (optional; the R script creates its own sample data)

HOW TO RUN IN RSTUDIO
1. Install/open R and RStudio.
2. Open student_performance_analysis.R in RStudio (File > Open File).
3. Click Source to run the whole script, or select all code and click Run.
4. View tables and summary in the Console.
5. View the bar charts, pie chart, and scatter plot in the Plots pane.
6. The script saves student_performance_report.csv and subject_average_report.csv
   in the current working directory. Use getwd() in the Console to see that folder.

PROJECT FEATURES
- Calculates total and average marks.
- Assigns pass/fail status and grades.
- Finds the highest-performing student.
- Calculates class and subject averages.
- Produces bar charts, a pie chart, and an attendance-vs-marks scatter plot.
- Exports results to CSV.

NOTE
This is a sample educational dataset, not real student records. The grade thresholds
are illustrative and can be changed to match your institution's rules.
